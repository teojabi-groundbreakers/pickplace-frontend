# FE 구성·실행·배포

React 19 · TypeScript · Vite 기반 상권 분석 FE 기본 구현입니다.

## 현재 구현 상태

화면 흐름은 **지도 탐색 → 지역·업종 선택 → 분석 요청 → 결과 확인**입니다. 첫 진입 시 결과를 자동 생성하지 않습니다. 저장한 분석을 다시 열면 해당 결과와 검색 조건을 복원합니다.

| 구분               | 현재 상태                                                                           |
| ------------------ | ----------------------------------------------------------------------------------- |
| 초기 구성          | React·TypeScript·Vite, 라우팅, HTTP 클라이언트, 환경변수 구성                       |
| 공통 UI            | 헤더·내비게이션·콘텐츠, 반응형 스타일, 디자인 토큰·공통 컴포넌트                    |
| 지역·업종 선택     | 계층별 선택 및 검증, 지도·검색 폼의 행정동 선택 동기화                              |
| 결과               | 종합점수·성장성·위험도·적합도, 영향 요인, 진단 요약                                 |

| 상태 처리          | 로딩, API 오류, 데이터 부족, 취소·타임아웃·재시도                                   |

| 운영 배포          | 정적 빌드·배포 설정 안내 준비, 실제 운영 배포는 미완료                              |
| 시각·실서비스 검증 | 내장 브라우저 연결 문제로 시각 검증 미완료. 카카오 실제 연결은 키 설정 후 검증 필요 |

최근 작업별 검증 기록과 제한 사항은 [WORKLOG.md](WORKLOG.md)를 확인합니다.

## 실행

```sh
pnpm install
cp .env.example .env.local
pnpm dev
```

기본값은 명시적인 **데모 모드**입니다. 서버 없이 일부 예시 지역·업종의 분석 흐름을 확인할 수 있습니다. 첫 화면은 지도 탐색이며 분석 버튼을 누른 후에 결과가 표시됩니다. 점수·통계·AI 문구·시설 마커·경계는 가상 예시입니다. 배경 지도는 카카오지도/별도 타일/OSM을 선택할 수 있으며, 외부 연결 없이 표시하는 기본 위치도도 제공합니다.

## 기본 기능

- 공통 레이아웃·반응형 내비게이션, CSS 디자인 토큰 및 버튼·배지·상태 UI
- 시·도/시·군·구/행정동 및 대분류/세부 업종 연동 선택·검증
- 분석 요청, 취소·타임아웃·응답 검증, 로딩/서버 오류/데이터 부족 처리
- 종합점수/성장성/위험도/적합도, 긍정·부정 영향 요인, AI 진단 요약
- 6/12개월 매출·유동인구·점포/개업/폐업 차트, 원본 데이터 표, 경쟁 비교
- 지도 우선 탐색, 지도/목록/검색 폼의 행정동 선택 동기화
- 카카오지도·별도 XYZ 타일·OSM 공급자 선택, 오류/타임아웃 시 기본 위치도 복구
- 선택 지역 중심·경계, 시설 레이어 필터 및 확대·축소
- 브라우저 로컬 분석 저장(최대 20개) 및 UTF-8 텍스트 보고서 다운로드
- `/` 분석, `/saved` 저장한 분석, `/guide` 이용 가이드

## 지도 설정

지도 선택 방법과 장애 대응은 [MAPS.md](MAPS.md)에 있습니다. `auto` 기본값은 카카오 앱 키가 있으면 카카오, 별도 타일 설정이 있으면 해당 타일, 모두 없으면 OSM을 초기 선택합니다. OSM 공용 서버를 사용하지 않으려면 `kakao`, `custom` 또는 `schematic`을 명시하세요. 명시한 공급자의 설정이 없거나 연결에 실패하면 기본 위치도로 전환할 수 있으며 OSM으로 암묵 전환하지 않습니다.

```dotenv
VITE_MAP_PROVIDER=kakao
VITE_KAKAO_MAP_APP_KEY=발급받은_JavaScript_앱_키
```

카카오지도 실제 연결에는 앱 키와 서비스 URL 등록이 필요합니다. 기본 위치도는 실제 도로지도와 구분하여 표시합니다.

## BE 연결

`.env.local`에 아래를 설정하고 개발 서버를 재시작합니다. 배포 시에는 환경변수를 변경한 뒤 다시 빌드해야 합니다.

```dotenv
VITE_DEMO_MODE=false
VITE_API_BASE_URL=https://your-api.example.com/api
```

`GET /catalog`, `POST /analyses`의 계약 초안은 [API.md](API.md)에 있습니다. 계약은 아직 BE 확정 전이며, 실제 API 모드에서는 서버 실패 시 데모 데이터로 대체하지 않습니다.

## 검증

```sh
pnpm format:check
pnpm test
pnpm lint
pnpm build
pnpm preview
```

지도 우선 표시·지역 선택 동기화, 지도 오류/무응답 복구, SDK 로더, 입력 계층 검증, API 계약·오류, 요청 경합, 결과 지표 전환과 저장 데이터 복원을 테스트합니다. 이용 가이드의 ‘화면 상태 확인’에서 데모 정상/부족/오류 시나리오를 확인할 수 있습니다.

코드 정리는 `pnpm format`으로 실행합니다. 줄바꿈·들여쓰기·JSX 속성·CSS 선언 기준은 [코드 작성 형식](DEVELOPMENT.md#코드-작성-형식)을 따릅니다.

## 구조

```text
src/components/  공통 UI, 검색, 점수, 차트, 지도, 인사이트
src/pages/       분석, 저장 목록, 이용 가이드
src/lib/         설정, HTTP 클라이언트, 검증, 요청 상태, 로컬 저장
src/data/        데모 목록·분석 fixture
src/types/       BE 연동 타입
src/test/        컴포넌트·API·상태 테스트
```

디자인 토큰은 `src/index.css`, 반응형 스타일은 `src/App.css`에 있습니다. 지도는 별도 청크로 지연 로딩합니다.

## 정적 배포

`pnpm build`의 `dist/`를 정적 호스팅 또는 Lightsail Nginx에 업로드합니다. BrowserRouter를 사용하므로 모든 FE 경로가 `index.html`로 fallback되어야 합니다. Nginx 예:

```nginx
server {
    listen 80;
    server_name your-domain.example.com;
    root /var/www/pickplace;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
    # 동일 출처 API를 사용할 경우 FE fallback과 분리합니다.
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

HTTPS·실제 서버 주소·도메인·API 배포는 운영 환경에 맞춰 설정합니다. 이 저장소 변경에는 실제 운영 배포가 포함되지 않습니다.

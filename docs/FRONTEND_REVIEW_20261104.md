# 프론트엔드 구현 및 AI 연동 검토

검토일: 2026-11-04 (Asia/Seoul). 대상은 `feature/1-map-workspace`의 `8075e11`과 같은 날 로컬 AI 연구용 결과다. 아래 지도·소개 기능은 당시 지도 브랜치의 관찰 기록이며 현재 `develop`에 병합됐다는 뜻이 아니다. 이 검토는 실서버 연동 완료를 뜻하지 않는다.

후속 반영: 점수·월별 지표의 부분 결측, 분기 연구 추정 UI, 기준값 0, 키보드 조작, 출처 유지에 대한 FE 변경을 추가했다. 실제 BE 연동과 승인된 운영 모델은 여전히 미완료다. 현재 응답 초안은 [연구용 계약](RESEARCH_FORECAST_CONTRACT.md)을 참조한다.

## 구현된 내용

- 지도 중심 화면, 지역·업종 선택, 분석 요청 및 결과 카드·추이·요약 UI가 있다.
- 기본값은 예시 데이터이며 실제 API 모드의 카탈로그·분석 요청과 오류·취소 처리가 준비돼 있다. 서버 연결은 확인되지 않았다.
- 분석 결과의 브라우저 저장·텍스트 다운로드, 소개·가이드, 반응형 CSS와 자동 테스트가 있다.

## 검토 당시 확인한 보완 사항

1. **실제 BE 연결과 카탈로그:** 현재 기본은 데모다([config.ts](../src/lib/config.ts), [api.ts](../src/lib/api.ts)). 서버 계약 초안인 `GET /catalog`, `POST /analyses`의 응답과 개발 환경·CORS/프록시를 BE와 확정하고 실서버로 검증해야 한다. 데모 지역·9개 업종과 별칭 코드는 실제 서울 전체 코드 목록이 아니다([demo.ts](../src/data/demo.ts)).
2. **AI 응답 계약과 부분 결과:** 검토 당시 [analysis.ts](../src/types/analysis.ts)와 [validation.ts](../src/lib/validation.ts)는 점수 네 종류와 월별 매출·인구·점포·개폐업·지역평균 숫자를 모두 요구했다. 이후 FE는 부분 결측을 처리하도록 변경했으며 성장률의 단위, 분기, null·사유, 데이터 기준일, 모델 버전, 연구용 경고에 대한 FE/BE/AI 합의는 남았다. 검토한 AI 산출물은 검증 전 연구용 분기별 전년 대비 매출 성장률이며 네 점수나 신뢰도·요인별 점수 기여도를 생산하지 않았다. 당시 최신 단기 모델은 FastAPI에도 연결되지 않았다.
3. **코드 체계:** 카카오의 10자리 행정동 H 코드와 서울 AI 자료의 8자리 `seoul-adstrd`는 같다고 가정하지 않는다. BE에서 공식 대응 관계·기준일 및 분동/통합 정책을 확인한 뒤 업종 코드 `CS...`와 함께 전달한다. 이름 추정이나 코드 자르기를 사용하지 않는다.
4. **지표 표시 의미:** [TrendChart.tsx](../src/components/TrendChart.tsx)는 점포당 월평균 매출·만원과 6/12개월을 가정하지만 AI 입력은 서울시 발행 기준을 보존한 분기 집계다. 데이터의 단위·대상·기간 및 산식을 확정해 그에 맞게 표시해야 한다. [Insights.tsx](../src/components/Insights.tsx)는 영향 요인을 종합점수 기여도·점으로 표기하지만 현재 단기 모델은 이를 제공하지 않는다. 단일 특징 치환 민감도 역시 가산 기여도나 인과효과가 아니다.
5. **명확한 계산 오류:** 검토 당시 추이 차트는 시작 값이 0이면 변화율을 0%로 표시했다. 후속 [TrendChart.tsx](../src/components/TrendChart.tsx)는 분모가 0일 때 계산 불가로 구분한다.
6. **출처와 결과 상태:** 검토 당시 `analyze`는 검증된 응답의 `source`를 무조건 `api`로 덮어썼다. 후속 [api.ts](../src/lib/api.ts)는 응답의 출처를 보존하며 연구용 경고를 표시한다. 테스트·연구·운영 결과의 최종 계약 합의는 남았다.

## 이후 개선 및 범위 확인

- [reports.ts](../src/lib/reports.ts)는 브라우저 localStorage에 최대 20건을 저장하고 텍스트 파일을 내려받는다. 다른 기기 동기화·계정 저장·PDF가 필요한지는 제품 범위부터 정한다.
- 차트 탭과 SVG 상호작용의 키보드 조작 및 스크린리더 동작을 확인한다([TrendChart.tsx](../src/components/TrendChart.tsx)). 실제 데스크톱·모바일 화면과 물리 트랙패드 검증도 필요하다.
- 시설 마커용 실제 데이터·지도 표시, 운영 도메인·HTTPS·정적 빌드 배포, 실제 서버 간 통합을 확인한다. 공식 행정동 경계/SGIS 연동은 기존 결정대로 후순위다.

## 검증 범위

- 자동 테스트 17개 파일·147개, lint, Prettier 검사를 실행해 통과했다. 모의 기반 테스트는 실제 BE·AI 연결이나 운영 지도 검증이 아니다.
- 임시 복사본에서 TypeScript 및 Vite 프로덕션 빌드를 통과했다. 원본 빌드 산출물과 캐시를 보존하기 위해 임시 빌드 정보 경로와 Vite runner 설정 로더를 사용했다.
- 실제 서버 연결 및 기기별 시각 검증은 이번 작업에서 수행하지 않았다.

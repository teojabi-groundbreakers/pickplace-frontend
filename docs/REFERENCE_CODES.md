# BE 기준정보 코드 대응 준비

[이슈 #16](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/16)의 선택 지역 위치 확인을 위한 FE 준비 코드다. 이 단계는 코드 대응 스냅샷과 검증 함수만 포함하며, 목록 선택 화면·지도 이동·카카오 역조회는 아직 연결하지 않았다.

## 출처와 범위

[고정 스냅샷](../src/data/seoulReferenceCodes.json)은 사용자가 제공한 BE `src/main/resources/reference-data/seoul-reference.json`에서 지역 대응 필드를 추출한 자료다. 버전 `seoul-reference-20262-mois-20261012-v1`, 행정안전부 코드표 대조 기준일 2026-10-12, 원본 SHA-256 `da5e5e5aaccc7f6ca0e2706dc925a6076274491211060bd386388759e35ec796`을 기록한다. BE의 자료 준비 기록에는 출처가 서울 열린데이터광장·서울신용보증재단·[행정안전부 코드표](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=130109), 원천 수집일이 2026-10-15, 공식 코드 대조일이 2026-10-16으로 기재되어 있다. 공식 코드 대조는 BE 기록을 근거로 하며 FE가 원본 코드표를 별도 검증한 것은 아니다. 지문 기록은 FE 실행 중 BE 원본을 재검증한다는 뜻이 아니다.

BE 목록의 자치구 코드·이름과 행정동 원천 코드·이름·소속·상태·버전이 스냅샷과 모두 일치하고 상태가 `CURRENT`인 경우에만 공식 H10 대응을 반환한다. 8자리 코드를 자르거나 `00`을 붙이거나 이름만으로 H10을 추정하지 않는다. 스냅샷은 공식 중심점과 행정동 경계를 제공하지 않는다.

## 남은 사항

이 자료는 2026-10-12 기준으로 고정되어 이후 변경을 자동 반영하지 않는다. 새 BE 기준정보 버전을 사용할 때 출처·기준일·코드 대응을 다시 검토해야 한다. 실제 위치 이동에는 장소 좌표의 카카오 행정동 역조회 결과와 H10의 일치 확인, 지도 UI·요청 경합 검증이 별도로 필요하다. 원천 자료의 이용 조건 독립 확인, FE/BE 담당자 검토·실제 서버·모바일·팀 리뷰 및 병합은 미완료다.

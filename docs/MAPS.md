# 지도 우선 흐름과 지도 공급자

## 화면 흐름

1. 분석 요청 전에도 지역 탐색 지도를 표시합니다.
2. 지도의 행정동 마커 또는 지도 아래 행정동 버튼으로 지역을 고릅니다. 검색 폼과 선택이 동기화됩니다.
3. 세부 업종을 선택하고 ‘상권 분석하기’를 누르면 점수·차트·진단을 표시합니다.
4. 검색 조건을 바꾸면 지도에서 이전 분석의 시설·경계를 숨깁니다. 이전 결과에는 재분석 안내를 표시합니다.

단순 지도 클릭 위치를 임의의 행정동으로 간주하지 않습니다. 현재는 BE 목록이 제공하는 행정동 중심 마커를 선택합니다. 임의 지점에서 행정구역을 찾으려면 실제 행정경계 또는 별도 역지오코딩 API가 필요합니다.

## 지원하는 지도

| 모드        | 표시 방식                                               | 필요한 설정                            |
| ----------- | ------------------------------------------------------- | -------------------------------------- |
| `kakao`     | 카카오지도 Web SDK, 행정동 선택·경계·시설 마커          | JavaScript 앱 키 및 서비스 URL 등록    |
| `custom`    | 허가받은 별도 타일 서버/자체 호스팅                     | Web Mercator XYZ 래스터 URL, 출처 표기 |
| `osm`       | OSM 공용 표준 타일, Leaflet                             | 키 없음, OSM 사용 정책 준수            |
| `schematic` | 외부 배경 요청 없는 기본 위치도, Leaflet                | 키·외부 지도 서버 없음                 |
| `auto`      | 설정된 카카오 → 설정된 별도 타일 → OSM 순서로 초기 선택 | 개발 기본값                            |

기본 위치도는 실제 위경도에 행정동 중심·제공된 경계·시설을 올립니다. **실제 도로나 지형을 표시하는 지도는 아닙니다.** OSM 타일을 다운로드하거나 저장해서 오프라인으로 제공하는 방식이 아닙니다.

카카오지도는 OSM 공용 타일 URL을 사용하지 않는 별도 SDK 경로입니다. 다른 OSM 기반 타일 공급자로 옮기는 경우에는 공용 서버 의존성은 줄어도 데이터 라이선스 의무까지 없어지는 것은 아니므로, 공급자별 조건을 확인해야 합니다.

## 카카오지도 사용

`.env.local` 예시:

```dotenv
VITE_MAP_PROVIDER=kakao
VITE_KAKAO_MAP_APP_KEY=발급받은_JavaScript_앱_키
```

[Kakao 지도 Web API 가이드](https://apis.map.kakao.com/web/guide/)에 따라 앱을 준비하고 개발/운영 서비스 URL을 등록합니다. 브라우저용 JavaScript 키를 사용하며 REST API 키나 관리자 키를 넣지 않습니다. VITE 환경변수는 번들에 노출되므로 허용 도메인 제한을 설정합니다. 계정 생성·약관 동의·앱 키 발급은 이 작업에서 수행하지 않았습니다. 실제 키가 없어 라이브 카카오지도 연결은 미검증이며, SDK 호출과 실패 처리는 구현되어 있습니다.

## 별도 타일/자체 호스팅

```dotenv
VITE_MAP_PROVIDER=custom
VITE_MAP_TILE_URL=/tiles/{z}/{x}/{y}.png
VITE_MAP_ATTRIBUTION=사용 허가를 받은 제공자의 필수 출처 표기
VITE_MAP_MAX_ZOOM=19
```

256px Web Mercator XYZ 래스터 타일을 사용합니다. HTTPS URL 또는 동일 출처 `/` 경로와 `{z}`, `{x}`, `{y}`가 필요하며, URL과 출처 표기가 모두 있어야 활성화됩니다. 타일 크기·좌표계가 다른 서비스는 어댑터가 추가로 필요합니다. Kakao/네이버의 비공개 타일 URL을 추출해 연결하지 않습니다. 라이선스·출처·캐시 조건은 사용 권한을 확보한 공급자 기준으로 설정합니다.

## 장애 대응

- Leaflet 타일: 한 로드에서 3회 이상 실패하거나 성공 타일 없이 실패한 경우, 또는 12초간 로딩이 완료되지 않으면 공급자를 전환합니다.
- 카카오: SDK 로드 실패/10초 초과, 지도 생성 실패, 타일 이미지 반복 오류/12초 초과에 대응합니다.
- 실패한 공급자는 제외하고 설정된 카카오/별도 타일을 시도한 뒤 기본 위치도로 전환합니다. **OSM은 다른 공급자의 암묵적인 대체 서비스로 사용하지 않습니다.**
- `kakao`/`custom`을 명시했는데 설정이 빠진 경우에도 OSM을 호출하지 않고 기본 위치도로 표시합니다.
- 복구 중 선택 지역·업종과 분석 요청 상태를 유지하며, 전환 알림과 ‘다시 시도’를 제공합니다.
- 사용자가 ‘기본 위치도’를 선택하면 배경 타일·카카오 SDK를 요청하지 않습니다. 이미 로드된 타일이나 SDK는 재선택 시 브라우저 캐시/런타임에 남을 수 있습니다.

환경변수 변경 후 개발 서버를 재시작하고 운영 배포는 다시 빌드합니다. 지도 선택 메뉴에서도 사용할 수 있는 공급자를 전환할 수 있습니다.

## OSM 공용 타일 관련 근거

[OSMF Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)는 공용 타일의 가용성/SLA를 보장하지 않으며 출처 표기와 캐시 준수 등을 요구합니다. 공용 타일의 일괄 다운로드 및 오프라인 타일 제공은 금지합니다. 따라서 운영 환경에서는 `kakao` 또는 허가받은 `custom` 공급자를 명시하고, 기본 위치도를 최종 대안으로 두는 구성을 권장합니다.

테스트는 지도·검색 조건 동기화, 타일 오류/무응답, 복구 순서, SDK 실패·재시도·타임아웃을 모의 환경에서 검증합니다. 실제 공급자 연결과 화면 배치는 운영 키 및 브라우저 환경에서 별도 확인이 필요합니다.

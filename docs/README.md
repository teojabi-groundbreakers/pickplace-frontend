## 현재 기준

- 모든 Git 작업은 [팀 개발 규칙](TEAM_RULES.md)의 Git Flow를 따른다. FE 적용 절차는 [개발 규칙](DEVELOPMENT.md#git-flow-적용)에 있다.
- 2026-10-08 원격 `develop`과 로컬의 기준 커밋이 `5a87a15`로 같음을 확인했다. 깨끗한 작업 트리에서 fetch·pull 후 [이슈 #1](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/1)의 `feature/1-map-workspace`를 생성했다. 원격 보호 설정·리뷰·병합은 아직 확인하거나 수행하지 않았다.
- 첫 화면은 지도 탐색이다. 지역·업종 선택 후 분석 요청을 실행하면 결과를 표시한다.
- 2026-10-12 사용자가 카카오맵의 정상 표시·동작을 확인한 뒤 카카오맵만 사용하도록 요청했다. 지도 선택 메뉴·다른 지도 렌더러·자동 전환을 제거하고 지도 관련 환경변수는 `VITE_KAKAO_MAP_APP_KEY`만 사용한다. 미설정·SDK/타일 오류는 카카오 안내와 같은 지도 재시도로 처리한다. 물리 트랙패드·모바일의 전체 확인을 뜻하지는 않는다. [카카오맵 단일 사용](MAPS.md#카카오맵-단일-사용)을 따른다.
- 모든 페이지의 사이드바는 기본 76px 아이콘 메뉴, 하단 `>`로 224px 전체 메뉴를 펼치는 공통 구조다. 로고·메뉴 위치와 페이지 이동 중 펼침 상태를 유지하며 `WORKSPACE` 제목을 제거했다. [공통 사이드바](FRONTEND.md#공통-사이드바)에 모바일 동작과 검증 범위를 정리했다.
- 2026-10-13 지도·저장한 분석·이용 가이드의 상단 바를 높이 56px·좌우 24px(760px 이하 16px)로 통일하고 지도 본문 높이와 공통 토큰으로 연결했다. [공통 상단 바](FRONTEND.md#공통-상단-바)를 따른다.
- 2026-10-13 사이드바 배너 ‘PickPlace 소개’는 `/about`의 서비스 소개로, 기존 메뉴 ‘이용 가이드’는 `/guide`의 사용 방법으로 분리했다. 소개에서도 공통 상단 바·사이드바 상태를 유지한다. [소개·가이드 역할](FRONTEND.md#서비스-소개와-이용-가이드)을 따른다.
- 기본 실행은 데모 모드이며 수치·평가·진단·분석 경계·시설 마커는 예시 데이터다.
- 2026-10-12 H10 독립 경계 조회·다중 폴리곤/구멍·지역명·출처·기준일 표시와 경계 전용 상태/재시도를 구현했다. [이슈 #7](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/7)에서 기존 지도 작업의 하위 범위로 관리한다. BE API가 아직 없다는 사용자 확인에 따라 FE를 먼저 준비했으며 실제 경계 서비스 연동은 미완료다. 기본 데모에서는 경계 HTTP 요청 없이 실제 경계 미제공을 안내한다. [독립 경계 흐름](MAPS.md#독립-경계-조회표시)을 따른다.
- 2026-10-20 경계 좌표를 FE 정적 파일로 제공하면 경계 BE 없이 표시할 수 있음을 조사했다. 후속 사용자 의견에 따라 서울을 포함한 전국 경계를 SGIS 읍면동 SHP 한 출처로 준비하는 방향이며, 서울 ZIP은 비교용 참고다. 코드/CRS/기준일·파일 분할·데모 분석 분리·갱신 조건은 [FE 정적 경계 대안](MAPS.md#fe-정적-경계-제공-대안)에 있다. 현재 앱은 기존 API 방식이며 실제 파일 수집·변환·정적 로더·실지도 검증은 미완료다.
- SGIS 연결을 위해 사용자는 같은 연도의 전국 읍면동 경계 원본 ZIP과 자료별 이용 조건을 준비한다. 공개 코드표·설명서 확보, 좌표 변환·H10 대응·정적 파일 연결은 FE/데이터 작업으로 진행한다. [자료 준비와 역할 분담](MAPS.md#sgis-자료-준비와-역할-분담)을 참조한다.
- 지도 메인 화면·상단 검색 오버레이·우클릭 행정동 조회는 `develop` 대상 [Draft PR #3](https://github.com/teojabi-groundbreakers/pickplace-frontend/pull/3)에서 진행하며 추가 시각 검증·리뷰·병합은 대기 중이다. 카카오 미세 이동 후 타임아웃 오탐 수정은 별도 [PR #4](https://github.com/teojabi-groundbreakers/pickplace-frontend/pull/4)로 `develop`에 병합되었다. 2026-10-12 최신 `develop` 병합으로 현재 feature 브랜치에도 반영했으며 이번 카카오 단일화에서 새로 해결한 문제와 구분한다.
- 카카오 SDK의 키 종류·허용 도메인 오류 이후 두 로컬 출처에서 SDK HTTP 200을 확인했다. `localhost:5173`에서 실제 도로지도·우클릭과 중심 위치의 행정동 조회 성공을 확인했고, 사용자가 드래그·더블클릭 정상 동작을 확인했다. 트랙패드 휠이 페이지 입력으로 처리되는 보고에 따라 지도 전용 휠 보정을 추가했다. 이전 축척 변화만으로 휠 정상 동작을 확정한 판정은 철회했으며 실제 트랙패드 재확인은 대기 중이다. [지도 조작](MAPS.md#카카오-지도-조작), 모바일 시각 검증·BE 연결·운영 배포의 제한을 확인한다.
- 2026-10-09 지도 확대·축소가 끊기거나 튄다는 후속 보고에 따라 즉시 배율 전환·160ms 입력 유실을 수정했다. 200ms 애니메이션과 SDK 실제 완료 이벤트로 다음 입력을 연결하며 전환 중에는 다음 한 단계만 보관한다. 전체 72개 테스트와 실제 지도의 자동 양방향 줌을 확인했으나 물리 트랙패드 체감은 재확인 대기다. [원인과 검증 범위](MAPS.md#확대축소-끊김-점검)를 참조한다.
- 2026-10-09 우클릭 카드의 지역 목록 검사를 제거하고 업종 선택 후 ‘이 지역 분석’·분석 호출 없는 ‘이 지역 둘러보기’를 추가했다. 실제 API 모드는 조회된 10자리 H 코드를 그대로 전달하며 BE 수용·실제 연결은 미검증이다. 카카오 둘러보기 확대와 점포명 표시는 데스크톱에서 확인했다. [상세 흐름](MAPS.md#지도-위치의-행정동-조회와-분석둘러보기)을 따른다.
- 데모 코드 불일치는 연남동 [이슈 #5](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/5), 성수2가1동 [이슈 #6](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/6)에서 별도로 처리한다. 실제 분석 요청을 FE 데모 목록으로 차단하지 않는다.
- 지역코드의 작성·조회·전달 기준은 [지역코드 문서](REGION_CODES.md)에 있다. 현재 데모의 2·5·8자리 구조와 지도 조회의 10자리 H 코드를 구분하며, 예시 목록의 공식 코드 일괄 검증·BE 코드 계약은 아직 완료하지 않았다.
- API 문서는 BE와 확정 전인 계약 초안이다.
- 백엔드 개발 착수 시 [인계 문서](BACKEND_HANDOFF.md)의 P0 작업·현재 FE 응답 제약·인수 시나리오를 확인한다. 기준 구현은 `145a050`이며 실제 BE 구현·계약 합의·서버 연결은 아직 완료하지 않았다.

최신 작업 내용과 검증 시점은 [작업 이력](WORKLOG.md)에서 확인합니다. 구현 상태가 바뀌면 이 문서와 해당 주제 문서를 함께 갱신합니다.

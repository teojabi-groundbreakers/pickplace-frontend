# FE 0.1.0 릴리스 준비

## 범위

`develop`의 `248e788`까지 병합된 FE를 기준으로 [이슈 #26](https://github.com/teojabi-groundbreakers/pickplace-frontend/issues/26)의 첫 시연용 릴리스를 준비한다. 지도 탐색, 지역·업종 선택, 분석 결과 화면, 저장한 분석, 이용 가이드와 서비스 소개를 포함한다. 이슈 #25의 후속 지역 조회 카드·시도 선택 작업은 포함하지 않는다.

기본 설정은 데모 모드다. 실제 BE–AI 분석 계약·통합, 서울 외 전국 지역 지원, 운영 도메인과 배포는 완료되지 않았다. 실제 모바일 기기와 물리 트랙패드 조작을 포함한 핵심 흐름의 팀 점검도 남았다. SGIS 경계 연계는 후순위다.

## 릴리스 절차

- 최신 `develop`에서 `release/0.1.0`을 생성한다.
- 릴리스 범위와 제한, 문서·버전 및 검증 결과를 확인한다.
- `main` 대상 PR을 생성하고 최소 1명의 리뷰 승인을 받은 뒤 merge commit으로 병합한다.
- 릴리스 내용을 `develop`에 반영하고 `main`에 `v0.1.0` 태그를 생성한다.

이 문서는 준비 범위를 기록하며, 실제 서비스 배포·팀 검증·리뷰·병합 또는 태그 생성이 완료됐다는 뜻은 아니다.

## 준비 사본의 자동 검증

2026-11-08 `develop` 기준 준비 사본에서 포맷 검사, 린트, 빌드와 자동 테스트 32개 파일·240개를 통과했다. 준비 사본은 기존 로컬 의존성을 사용했다. 자동 검증과 실제 지도·서버·모바일 기기 및 팀 핵심 흐름 점검은 별개다.
